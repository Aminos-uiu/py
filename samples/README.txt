MiniDAW sample library  (Sampler > Melodic > Library button)

Every audio file in this folder (wav / mp3 / flac) appears in the Library menu.
Each subfolder becomes a submenu. You can add, rename or delete files and folders at any time:
the menu reads the folder every time you open it.

Root note: put the pitch of the sample in brackets at the end of the file name, e.g.
    My bell (C5).wav      Bass pluck (E2).wav      Voice (F#4).wav
(C4 = middle C). The keys then play in tune right away. Without a note in the name,
MiniDAW detects the pitch automatically when you pick the sound.
